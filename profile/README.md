# fish-trait-network

fish-trait-network is a collaborative effort to compile life-history estimates for all fishes.  It is envisioned to have three stages:

1.  Data compilation
2.  Analysis
3.  Distribution

So far it contains two components:

* `fishtraitR` is an R-package to easily access predicted life-history estimates
*  `dist-thorson-elephantfish` contains a compressed database of predicted life-history estimates from Thorson et al. (In preparation)

We encourage analysts to contribute repositories to the organization, which would contain stage-1 (Data), stage-2 (analysis), or stage-3 (distribution) components.  The suggested naming convention is [stage]-[lead]-[keyword].
